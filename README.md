Module 8 Journal

1. How can I ensure that my code, program, or software is functional and secure?

    To make sure that my code, program, and or software is functional and secure I can begin by carefully testing it against its requirements
    and validating both the correct and incorrect inputs. Throughout this course, I used unit tests to check that valid data was accepted
    and that invalid data was being rejected, which helped to prevent errors from happening. By testing each rule one at a time, like through
    field length limits or the required values, I could confirm that the program was behaving as expected. Writing automated tests also makes
    it easier to catch problems early on whenever changes are made, so doing this in the future will improve readability and reduce the chance
    of running into any unexpected issues.

2. How do I interpret user needs and incorporate them into a program?

   I interpret the needs of users by closely looking at the requirements and turning each rule into clear program logic and test cases.
   In the Contact, Task, and Appointment services, the requirements defined what data was to be allowed, what was required, and what should
   not be accepted. I used these rules to guide me on how the classes needed to be written and how the tests should be designed. By directly
   mapping each of these requirements to a test, I made sure the program matched what the user needed and handled the errors properly whenever
   incorrect data was given.

3. How do I approach designing software?

   I approach designing software by breaking the problem down into smaller parts and focusing on one requirement at a time. I start
   by defining the data and rules for each object, and then build simpler methods that will follow those rules. After that, I can create
   tests to confirm that each part is working correctly before I move on. This step-by-step approach will make the software easier for me
   to understand, test, and update. It will also help me make sure that the final program meets the requirements and makes it easier for
   me to maintain.
